## 2. 역할 정의와 우리 실험체 배정

### 2-1. ER 커뮤니티의 포지션 분류 (요약)
- **하드 이니시에이터**: 대시+CC로 먼저 걸어 진형을 무너뜨림. 이길 수 없으면 옆으로 들어오는 적을 끊는 역할로 전환. 점사 대상에 핑. [ER] 스쿼드 공략
- **탱커**: 우세하면 먼저 밀고, 밀리면 들어오는 적을 저지하며 원딜 딜각을 봐줌. **원딜과 1:1을 하러 뛰어들면 아군 원딜이 무방비** → 적 브루저 진입을 막는 게 본업. [ER] 스쿼드 공략
- **브루저/어그로 근딜**: 아군 옆에서 같이 치기, 먼저 들어가 진형 붕괴, 뒤로 돌아 노출된 원딜 사냥 중 상황에 맞게 선택. 한 판 안에서도 역할이 계속 바뀐다. [ER] 스쿼드 공략, 구도공략 6편
- **암살자(다니엘·캐시 등)**: 스쿼드에서 난이도 최상. 돌아가서 원딜을 먼저 지우는 게 강점이지만 **반반 구도의 정면 밀기에서는 브루저보다 약하다.** 성장 우위면 앞라인부터 녹여 2:3 만들기도 가능. [ER] 스쿼드 공략
- **1.5선 원딜**: 앞라인 살짝 뒤~같은 선. 스킬로 부쉬 시야를 먼저 뚫고 카이팅으로 적 앞라인을 반쯤 깎아 이니시를 돕는다. [ER] 스쿼드 공략
- **2선 원딜(나딘·리오 등)**: 탱커 후방. 적 스킬 범위를 절대 허용하지 않음. 밀려 들어오면 백무빙, 확실한 각에서만 앞대시. 생존기는 적 스킬을 세며 확실히. [ER] 스쿼드 공략
- **포킹 원딜(저격 등)**: 적 스킬이 닿지 않는 거리에서 깎고, 상대가 못 참고 들어올 때 체력 우위로 받아친다. 하드 이니시·브루저·양각에 약함. [ER] 스쿼드 공략

### 2-2. 이 시뮬레이터 실험체 6명 배정

|---|---|---|---|---|
| **캐시** | 한타형 암살/브루저 | 1~2선 (탱커가 없으므로 앞라인 대행) | E(수쳐)로 **2인 관통/벽꿍 기절**을 노리는 한타 개시자. E 빗나가면 영향력 급락 → E는 각이 날 때만 | [ER] 나무위키 캐시 |

- 탱커가 없는 로스터이므로 **"탱킹" 역할 공백**이 생긴다(구도공략 3편: 빠진 역할은 누군가 억지로 맡는다). → 근접(캐시/다니엘)이 있으면 캐시가 1선, 둘 다 없으면(원딜 3명) 아야가 1선 대행. [ER]+[추정]
- 2:2에서는 "1선+원딜" 또는 "근접 2" 또는 "원딜 2" 구성이 나온다. 원딜 2 구성은 CC 부족이 약점(에펨 "일탱 투원딜" 글: 노CC 원딜 조합은 피하라) → 원딜 2 팀은 `stance='hold'`(받아치기) 고정 권장. [ER]+[추정]

### 2-3. 역할 배정 알고리즘 [추정, 구도공략 3편 원리 적용]
```
1. 근접(캐시>다니엘) 중 체력·방어 높은 쪽 = frontline. 없으면 아야 > 리오 > 나딘 > 카티야 순.
2. 다니엘 = flanker (frontline이 다니엘뿐이면 다니엘은 frontline 대행하되 진입은 '확실한 근거'에서만).
3. 원딜 중 사거리 가장 긴 쪽 = poke(3선), 나머지 = carry(2선/1.5선).
4. focusCaller(점사 지정자) = 플레이어가 아군이면 플레이어, 아니면 frontline.
```

## 3. 포지셔닝 (아군·적 기준 위치)

### 3-1. 기본 대형
- 아군 무게중심 `C`, 적 무게중심 `E`, 전방 단위벡터 `f = norm(E - C)`.
- 역할별 목표 위치 = `C + f * offset + perp(f) * side` 를 기준으로 하되 각자 사거리 규칙이 우선.

| 역할 | offset (전방) | side (좌우) | 규칙 | 출처 |
|---|---|---|---|---|
| frontline | +1.5 ~ +2.5m | 0 | **무조건 최전방일 필요 없음.** 팔 길이가 우리가 길면 원딜과 거의 같은 선(+0.5m)에 서서 원딜을 지킬 준비만. 적 원딜 사거리 안으로 몸이 쏠리면 의미 없이 체력만 깎임 | [ER] 구도공략 2편, 디시 포지션 잡는법(2026-02) |
| carry(2선) | -1.5 ~ -3m | ±1m | 탱커 후방. 적 스킬 범위 밖. 팔 길이 유리하면 1선 근처까지 라인을 당겨도 됨 | [ER] 스쿼드 공략, 구도공략 2편 |
| 1.5선(아야) | -0.5 ~ -1m | ±1.5m | 앞라인 살짝 뒤. 부쉬 시야를 스킬로 먼저 확인 | [ER] 스쿼드 공략 |
| poke(3선, 카티야) | 최근접 적과 `사거리 - 0.5m` 유지 | 반대편 측면 | 적 이니시 루트 반대쪽으로 돌아서 때림(예: 적 블링크 이니시가 오른쪽이면 왼쪽으로) | [ER] 구도공략 2편 |
| flanker(다니엘) | 적 측면 90° 방향, 적 원딜과 6~8m | 부쉬 우선 | 정면 대형에 끼지 않음. 시야 밖 대기 | [ER] 스쿼드 공략, [MOBA] metabot |

### 3-2. 간격 규칙
- **뭉치지 않기**: 아군끼리 최소 2.5m [추정] 간격. 캐시 E(2인 관통)·광역 CC 한 번에 둘이 잡히지 않게. LoL 자료: 한 번의 이니시에 셋 다 잡히지 않게 대각선으로 퍼지기, 적 광역 궁이 살아 있으면 넓게, 빠지면 좁게. [MOBA] metabot, mobatrainer
  - 시뮬레이터 수치: 캐시 E 관통 폭(hitWidth 1.2m) 기준으로 **적 캐시 E가 살아 있으면 서로 직선 정렬을 피하고 3m 이상** [추정].
- **너무 멀지 않기**: 아군 최근접 거리 6m 이내 [추정] (원형 투기장 반지름 17m, 시야 8.5m → 6m면 서로 시야 안이고 2~3초 안에 합류). 아레나 자료: 2:2에서는 항상 파트너 근처에서 같은 적에게 스킬을 몰아야 함. [MOBA] dodge.gg, thebackdash
- **원딜-앞라인 거리**: 앞라인은 "원딜을 무는 적에게 바로 스킬을 써서 떼어낼 수 있는 거리"를 유지 → 캐시 기준 Q 돌진 4m 이내, 즉 **원딜과 3~4m** [ER 원리 + 추정 수치].
- **벽 근처 금지(아군 원딜)**: 적에 캐시가 있으면 원딜은 벽에서 2m 이상(기존 1:1 무빙 ⑤ 재사용). 팀에서는 **아군 둘이 적 캐시의 E 직선 위에 서는 것도 벽과 같은 취급**(2인 관통 기절). [추정, 캐시 E 판정 근거]

### 3-3. 원형 투기장 특화 [MOBA 아레나 원리 + 추정]
- 바깥 경계에 몰리면 도망칠 공간이 없다 → 원딜은 투기장 중심에서 **반지름 12m 바깥으로 밀리지 않기** [추정]. 적을 바깥으로 밀고 우리는 중앙을 차지(아레나 "불의 고리"에서 적을 가장자리로 미는 원리). [MOBA] dodge.gg

## 4. 교전 개시(진입) 판단

### 4-1. 팀 전략 상태: 무는 팀 vs 받아치는 팀
```
reachUs  = 아군 원딜 최대 사거리(없으면 근접 진입 사거리)
reachThem= 적 원딜 최대 사거리
stance = (reachUs < reachThem - 0.5m) ? 'dive' : 'hold'      // 팔 길이 불리 → 우리가 변수를 냄
```
- **불리한 팀이 먼저 박고, 유리한 팀은 받아친다.** 둘 다 기다리면 팔 짧은 쪽이 일방적으로 깎임. [ER] 리다의 한타 구도공략
- 같은 조합도 상대에 따라 무는 쪽/받는 쪽이 바뀜 → 매 판 시작 시 재계산 [ER].
- `hold` 팀도 무한정 기다리지 않음: 기존 1:1의 "8초 견제 후 4초 진입" 규칙을 팀 단위로 확장 → 12초 동안 교전이 안 열리면 체력 우위 쪽이 진입 [추정].

1. 체력 합 비율: 아군 유효체력 합 / 적 ≥ 1.0
2. 핵심 쿨: 아군 진입·CC 스킬 준비, 적 핵심 스킬 1개 이상 빠짐
3. 인원: 아군 ≥ 적
4. 위치: 적이 벽/경계 쪽, 또는 적 1명이 고립

→ `score >= 3` 진입, `score <= 1` 후퇴 준비, 2면 `stance` 따름 [추정].

### 4-3. 누가 먼저 들어가나 (진입 순서)
1. **frontline이 먼저 커밋.** 원딜은 탱커를 따라 들어가지 않고 간격 유지. [MOBA] metabot / [ER] 스쿼드 공략 원딜 팁 2("아군이 들어간다고 같이 무리하게 진입하지 않는다")
2. **암살자는 마지막.** 탱커·브루저가 먼저 어그로를 받은 뒤, 적 이동기·CC가 빠진 뒤 진입. 혼자 먼저 들어가는 상황 절대 회피. [ER] 나무위키 쇼이치·엠마·다니엘
3. **이니시 스킬을 쥐고 뒷짐 지지 않기**: 좋은 이니시가 있는데 원딜 피지컬에만 맡기면 안 됨 → 캐시 E 각(2인 정렬 또는 적 뒤 벽 1.5m 이내)이 나오면 frontline 캐시는 즉시 사용. [ER] 디시 「탱커의 역할」
4. **탱커는 "지키기"와 "이니시" 중 하나만**: 둘 다 하려 하면 둘 다 실패 → 팀 stance에 따라 frontline 모드를 `guard` 또는 `engage` 하나로 고정(재평가 주기 3초) [ER 원리 + 추정 주기].

### 4-4. 아군 진입에 호응 (follow-up)
- 아군 이니시가 들어가면 **사이드에서 상대 원딜을 압박하던 아군이 바로 호응**. 호응이 없으면 한 명만 들어가 한타가 끝난다. [ER] 구도공략 4편
- 호응 반응시간: 난이도별 기존 `diff.react` 사용, 쉬움 0.6s / 보통 0.35s / 어려움 0.2s 정도 [추정].
- **진입하기 전 아군 진입 스킬 유무 확인**: 한 방에 녹일 딜이 아니면 같이 들어갈 브루저(캐시) 스킬이 있는지 먼저 본다. 핵심 스킬이 없을 때 궁을 쓰면 호응이 안 됨. [ER] 아카라이브 리플 분석 글 댓글(검색 요약 기준)

## 5. 타겟 선정

### 5-1. 기본 원칙
- **팀 전원이 같은 대상**(포커싱). 한 명을 빨리 지워 2:3을 만드는 게 3:3의 핵심. 점사 대상은 이니시에이터/콜러가 핑으로 지정. [ER] 스쿼드 공략, 기존 노트 3-2
- **역할별 기본 대상이 다르다**:
  - 원딜(carry/poke): **닿는 가장 가까운 적**(대개 적 앞라인)부터. 적 원딜만 고집하지 않음. 적 앞라인이 무너지면 뒤로 전환. [MOBA] mobatrainer·metabot / [ER] 스쿼드 공략(2선 원딜은 "다가오는 적을 제거")
  - frontline(캐시): 적 앞라인이 아니라 **아군 원딜에게 오는 적**(브루저·암살자) → 그다음 적 원딜. [ER] 스쿼드 공략(탱커는 적 브루저 진입 저지)
  - flanker(다니엘): **체력 낮은 적 원딜 최우선**, 탱커·체급 높은 브루저는 후순위. [ER] 나무위키 다니엘
  - 캐시 E: 적 원딜 우선, 2인 관통 각이면 대상 무관하게 2인. [ER] 나무위키 캐시
- **상대 원딜 화력이 아군 원딜보다 강하면** 아군 원딜을 일부 포기하더라도 상대 원딜을 문다. [ER] 구도공략 6편

### 5-2. 점수식 [추정, 위 원칙을 가중치로]
```
score(t) =  40 * (1 - t.hp/t.maxHp)                     // 잃은 체력 비율
         +  25 * (t.role in {carry, poke})              // 딜러 가중
         +  30 * (t.stun > 0 || t.root > 0 || t.slowed) // CC 걸린 적 (연계)
         +  25 * (t === focusTarget)                    // 콜러/플레이어가 치는 대상
         +  20 * (t가 아군 원딜에게 4m 이내)              // 필 대상 (frontline은 x2)
         +  15 * (내 콤보로 처치 가능: 예상딜 >= t.hp)    // 킬각
         -  2.0 * max(0, 경로 거리 - 내 사거리)            // 멀수록 감점 (m당)
         -  35 * (t까지 가려면 적 앞라인 3m 이내를 지나야 함 && 내 역할 != flanker)  // 앞라인 넘어 다이브 금지
         -  20 * (t.untargetable || t.shield 큼)           // 다니엘 R 무적, 아야 보호막
```
- 원딜은 `경로 거리` 대신 `현재 위치에서 사거리 안` 여부만 봄(사거리 밖 대상은 점수 무시, 쫓아가지 않음).

### 5-3. 타겟 전환 규칙
- **유지(히스테리시스)**: 새 대상 점수가 현재 대상보다 15점 이상 높을 때만 전환, 최소 유지 1.2초 [추정] (흔들림 방지).
- **즉시 전환**:
  1. 적이 내 사거리 안으로 들어와 나를 위협(측면 진입한 암살자) → 원딜은 그 적으로 전환. [MOBA] metabot ("측면으로 들어온 적이 옆에 착지하면 그걸 친다")
  2. 현재 대상이 무적/은신(다니엘 R·E) → 다른 대상. [추정]
  3. 아군 CC가 다른 적에게 들어감 → 그 적으로(0.3초 창). [ER 원리]
  4. 처치 가능한 적이 사거리 안 → 마무리 우선. [추정]
- **매 킬 후 재배치**: 킬 직후 제자리에 서 있지 말고 재정렬(적이 몰려올 수 있음). [MOBA] metabot

## 6. 후퇴·재정비·추격 한계

### 6-1. 후퇴 트리거
| 트리거 | 행동 | 출처 |
|---|---|---|
| 수적 열세 (아군 < 적) 이고 체크리스트 ≤ 1 | 팀 전체 후퇴(중앙 반대편 기둥 뒤로) | [ER] 기존 노트 3-4, [MOBA] mobatrainer |
| 아군 핵심 스킬 소진 (frontline 진입기+CC 모두 쿨) | 앞라인 후퇴, 원딜은 카이팅으로 시간 끌기 | [ER] 기존 노트 3-4 |
| 내 체력 < 30% (원딜) / < 25% (근접) 이고 적이 사거리 안 | 개인 후퇴 + 핑퐁 요청 | [추정, 기존 `meleeAI.lowHp 0.3`과 맞춤] |
| 아군 1명 사망 직후 | 남은 인원 비교 후 재판단. "차라리 계속 싸우거나 아예 빠져서 다음을 노리는 게 살길" — 어정쩡하게 시체 근처에서 머뭇거리지 않음 | [ER] 나무위키 가이드(검색 요약) |
| 적 원딜만 남았는데 나도 위험 | "적 하나 잡고 내가 죽을 상황이면 나 없이 남은 아군이 이길 수 있는지" 따져 1:1 교환 판단(6-3) | [ER] 스쿼드 공략 원딜 팁 4 |

### 6-2. 핑퐁 (어그로 교대) — 가장 중요한 팀 규칙 [ER] 구도공략 5편
- 아군 A가 포커싱을 받아 빠지면, **B·C는 A와 같은 방향으로 따라 도망가지 않고 자리를 지킨다.** 그러면 적 어그로가 B로 넘어가고, 적은 쉽게 못 들어온다. 같이 도망가면 적 포커싱이 A에게 계속 남아 A가 죽는다.
- 원딜도 핑퐁에 참여해야 함: 앞라인 생존기가 다 빠졌는데 원딜이 "맞기 싫어서" 계속 뒤로만 빠지면 앞라인만 먼저 죽고 한타가 무너진다. "한 명이 안 맞으면 남은 딜을 누군가 더 맞는다."
- AI 구현 [추정]:
  - `pressured(u)` = 최근 1.5초 동안 받은 피해 ≥ maxHp의 15%, 또는 적 2명 이상이 u를 공격 중.
  - u가 pressured → u는 이동기로 뒤로(아군 반대쪽 아님, **아군 쪽으로**) 빠지고, 체력 가장 높은 다른 아군이 1~2m 전진해 어그로 획득(근접은 대상에게 진입, 원딜은 사거리 끝까지 전진해 평타).
  - u의 체력이 회복되거나 보호막이 돌면 다시 교대.
  - 원딜의 앞라인 대행 전진은 자기 체력 ≥ 60% 일 때만 [추정].

### 6-3. 1:1 교환과 청소(마무리)
- 1-for-1 교환: 남은 인원 기준 **교환 후에도 아군이 수적 동률 이상이고 체력 합이 우위**면 교환 수락. 3:3 → 2:2는 체력 우위일 때만, 2:2 → 1:1은 거의 수락하지 않음(아레나 자료: 2:2가 1:2보다 거의 항상 낫다). [ER 원리 + MOBA dodge.gg + 추정]
- 원딜이 죽으면 아군 딜이 사라진다고 생각할 것 — 원딜은 교환 수락 문턱을 더 높게(체력 합 우위 1.3배 이상) [ER] 스쿼드 공략 + [추정 수치].
- 청소(cleanup): **적 앞라인이 죽고 인원이 줄었을 때만** 뒷라인을 쫓는다. [MOBA] metabot

### 6-4. 추격 한계 [추정]
- 추격 최대 거리: 아군 무게중심에서 8m(= 시야 8.5m 이내) 또는 3초.
- 도망치는 적이 부쉬/시야 밖으로 들어가면 직접 쫓지 말고 원딜 스킬·드론으로 확인 후 진입(기존 노트 2-2, 부쉬 확인 원칙). [ER]
- 다니엘 E(은신 돌진)는 **도망치는 적을 잡도록 아껴 둔다**(기존 `meleeAI` 규칙의 팀 버전). [ER]
- 카티야 R/리오 화궁 R은 **도망치는 적 마무리**에 쓰는 것이 기본(난전 중 고정 채널링 금지). [ER] 나무위키 카티야·리오

### 6-5. 재집결 (regroup)
- 후퇴 판정 시 집결 지점 = 아군 무게중심에서 적 반대 방향 4m, 기둥이 있으면 기둥 뒤 [추정].
- 시즌 12 휴식 개편(전투 중 단계형 휴식 가능)으로 **잠깐 빠져 체력 회복 후 재교전**의 가치 상승 → 집결 후 2~4초 휴식(시뮬레이터 S3 재생 활용) 후 재평가. [ER] 기존 노트 3-4
- **혼자 싸우지 않기**: 아군 최근접 > 6m 이고 적 2명 이상이 6m 안이면 무조건 아군 쪽으로 이동. [ER] 나무위키 가이드(혼자 행동 위험), Steam 스쿼드 토론 + [추정 수치]

## 7. 필(보호)·카이팅·CC 연계

### 7-1. 필 (암살자/브루저가 원딜을 물 때)
- **frontline은 적 브루저/암살자가 뒷라인으로 가는 길을 막는 게 본업.** 탱커가 적 원딜과 1:1 하러 가면 아군 원딜이 무방비. [ER] 스쿼드 공략
- 단, **원딜이 물렸다고 frontline이 무조건 원딜에게 붙으면 안 된다**: 상대 앞라인이 프리딜을 얻고 광역기가 원딜 쪽에 같이 맞음. 앞에서 버텨 2:1 구도를 만드는 게 나을 때가 있다. → 판단: 원딜을 문 적이 **암살자 1명**(다니엘)이면 필, 적 **앞라인 전체가 밀고 들어오면** 자리 유지. [ER] 구도공략 2편 + [추정 분기]
- 1선이 원딜에게 붙어버렸다면 2선이 1선 역할을 대신 맡는다(3:3). [ER] 구도공략 2편
- **CC는 아껴 둔다**: 적에 암살자가 있으면 frontline CC(캐시 E)를 암살자 진입 대응용으로 보유. CC를 먼저 다 빼면 딜러를 못 지킨다. [ER] 디시 탱커 관련 글(검색 요약)
- 적 다니엘이 보이지 않을 때(은신/미확인): 아군 원딜은 frontline 3m 이내 밀착, 한 걸음 뒤로. [MOBA] mobatrainer("적 정글이 안 보이면 플랭크를 가정하고 한 걸음 뒤")
- 은신 대응: 다니엘 E 연기 이펙트/흔들리는 부쉬 감지 → 망원 카메라를 자기 발밑·원딜 주변에 설치. [ER] 기존 노트 2-2·3-4, 나무위키 다니엘(카메라·시야 싸움에 취약)
- 필 수치 [추정]: 적 근접이 아군 원딜 3.5m 이내 진입 → frontline이 대상 전환(점수 x2), 원딜 아야는 R(자기 중심 CC) 사용 조건 = 근접 적 2.5m 이내.

### 7-2. 팀 카이팅 (원딜)
- 기존 1:1 무빙 ①~⑥은 그대로 쓰고, 팀에서는 **백무빙 방향을 "적 반대"가 아니라 "아군 frontline 쪽"**으로 보정(다이버를 아군 앞라인에 끌고 오기). [MOBA 원리 + 추정]
- 2선 원딜 규칙: 적 스킬 범위 절대 허용 안 함, 밀고 들어오면 백무빙, **확실한 각에서만 앞대시**, 생존기(리오 E·나딘 E·카티야 E·아야 E)는 적 스킬을 세며 확실히 → 위험 스킬(적 캐시 E, 다니엘 R) 쿨이 남아 있으면 이동기 보유(기존 ⑥과 동일). [ER] 스쿼드 공략
- 원딜 공통: **적 CC(그랩·대시 CC)가 살아 있으면 무리하지 말고 탱커 뒤에서 버틴다.** [ER] 스쿼드 공략 원딜 팁 3
- 포킹(카티야): 먼저 박지 않고 견제, 상대가 못 참고 들어올 때 체력 우위로 받아친다. 견제 없이 교전 중 평타만 치는 원딜은 역할 실패. [ER] 스쿼드 공략, 디시 포지션 잡는법
- 나딘 W 덫: 교전 전 적 진입 경로(아군 원딜 앞 2~3m)에 깔기, 적이 교전 중 쉽게 부수지 못하는 위치. E 와이어는 후퇴용이면 뒤쪽 4~5m에 미리. [ER] 나무위키 나딘 + [추정 수치]

### 7-3. CC 연계·폭딜 타이밍
- 아군 CC가 적에게 들어가면 **딜러 전원이 그 대상에 폭딜**(나딘 Q·아야 W 등 스킬샷은 CC 걸린 대상에게 적중률이 높음). [ER] 나무위키 나딘·아야, 스쿼드 공략(메이지는 아군 CC에 맞춰 연계)
- **CC 겹치기 금지 [MOBA 일반 원리, 추정]**: 이미 기절 중인 대상에게 다른 아군 CC를 바로 쓰지 말고 기절 종료 0.1~0.2초 전에 이어서 사슬 연장.
- 캐시 E 2인 관통: 적 둘이 E 직선(폭 ≈1.2m) 위에 정렬되면 frontline 캐시의 최우선 행동. 이후 W 바깥 범위 → Q 둘 다 → Q 재사용(기존 combo `double`). [ER] 나무위키 캐시, 기존 config
- 리오 단궁 R 벽꿍 기절, 캐시 E 벽꿍: 적이 벽/기둥 1.5m 이내일 때 노리기. 원형 투기장 경계 벽도 벽 취급인지는 구현 확인 필요(최근 커밋: 스냅샷 경계 벽 제외). [ER] 나무위키 리오·캐시
- 궁극기 아끼기: 허공 궁 금지, 확실한 대상에게. [ER] 스쿼드 공략(메이지 궁)
- 다니엘 R(무적): 진입 직후 적 CC를 받을 타이밍에 써서 CC 회피 + 딜, 끝나고 E로 이탈 준비. [ER] 나무위키 다니엘

## 8. 시야·부쉬·플랭크 (팀 버전)

- **모든 구도는 적 전원 위치를 안다는 가정** — 드론/카메라로 적 위치부터 확보. 위치를 모르면 구도 판단 자체가 무의미. [ER] 구도공략 2편, 구도공략 6편(시야 선점이 전제)
- 역할별 시야 임무 [ER 원리 + 추정 분배]:
  - poke(카티야): W 드론으로 적 대열·부쉬 확인, 함정/카메라 정리. 교전 시작 전 1회.
  - 1.5선(아야): 스킬을 수상한 부쉬에 던져 확인. (단, 아야 총알은 시야를 주지 않음 → 맞았는지만 판정)
  - frontline: 망원 카메라를 아군 원딜 옆(적 다니엘 대비) 1개.
  - flanker(다니엘): 적 카메라가 깔린 경로는 피해서 우회.
- 부쉬: 아군 원딜이 부쉬 앞에 서지 않음(확인 전). 적이 부쉬에 들어가면 쫓지 않고 확인 먼저. [ER] 기존 노트 2-2
- 플랭크(측면 진입): 브루저/암살자는 상대 2선과 맞대는 게 불리하면 돌아서 변수를 만든다. 다니엘은 정면 대치가 이어지는 동안 부쉬→측면 90°로 이동, 적이 아군 frontline과 교전을 시작하면(적 핵심 스킬 사용 후) 진입. [ER] 구도공략 2편·6편, 나무위키 다니엘
- 적 플랭크 대비: 적 다니엘/캐시가 5초 이상 미확인이면 "플랭크 중"으로 간주 → 원딜 한 걸음(1m) 뒤, frontline 쪽 밀착. [MOBA] mobatrainer + [추정 수치]
- 시야 8.5m vs 원딜 사거리 ~6m, 카티야 Q 11m: **시야보다 긴 스킬은 아군 시야 공유가 있어야 쓸 수 있다** → 팀 시야 공유를 구현하면 카티야가 아군이 본 적을 저격하는 구도가 생김(팀 시야 공유가 실제 게임 규칙). [추정: 구현 제안]

## 9. 플레이어가 리더일 때 (아군 AI 규칙)

ER 자료에 직접 없는 부분. 핑/점사 콜 문화(이니시에이터가 점사 대상 머리 위에 핑)와 "아군 이니시에 호응" 원칙을 플레이어 중심으로 옮김. [ER 원리 + 추정]

1. **focusTarget = 플레이어가 마지막으로 공격/스킬을 맞힌 적** (2초 유지). 아군 AI 타겟 점수에 +25(5-2), 원딜은 사거리 안이면 사실상 고정.
2. **진입 결정권은 플레이어에게**: 플레이어가 적 4m 이내로 들어가거나 스킬로 진입하면 = "팀 진입" 신호. 아군 AI는 4-4 호응 반응시간 안에 따라 들어감(원딜은 따라 들어가는 게 아니라 사거리까지만 전진).
3. 플레이어가 뒤로 빠지면(적과 거리 증가 + 체력 < 50%) = "후퇴" 신호 → 아군도 후퇴하되 **핑퐁 규칙대로 한 명은 자리 유지**해 플레이어에게 붙은 어그로를 끊어 줌.
4. **포지션 양보**: 플레이어가 캐시(근접)면 아군 AI는 frontline을 맡지 않고 2선/측면으로. 플레이어 진입 경로(플레이어→focusTarget 직선 ±1.5m)에 서지 않음 — 특히 캐시 E·Q 경로를 막지 않게. 아군 근접 AI(다니엘)는 플레이어와 같은 대상을 다른 각도(측면)에서.
5. **킬 스틸 회피 안 함**: 마무리는 누가 해도 됨. 대신 플레이어가 콤보 중(평타 강화·E 기절 직후)일 때 아군 CC를 덮어 쓰지 않음(7-3 CC 겹치기 금지).
6. 수동 명령(제안): 핑 키 — `공격`(대상 지정), `후퇴`, `모여` 3종. 나무위키 가이드의 Alt+드래그 핑 체계(교전 개시/위험/모이기)와 Shift+클릭 퇴각 핑에 대응. [ER] 나무위키 가이드
7. 플레이어가 혼자 너무 깊이 들어가면(아군 무게중심에서 8m 초과, 적 2명 이상 근처): 아군 AI는 따라 죽으러 가지 않음 — 원딜은 사거리 끝에서 지원만, 근접은 진입 체크리스트 재평가. ("아군이 들어간다고 무리하게 같이 진입하지 않는다" [ER] 스쿼드 공략 원딜 팁 2)

```js
teamAI: {
  think: 0.25,                 // 팀 전략 재평가 주기(s); 개인 판단은 기존 diff.react
  stanceRecalc: 3.0,           // frontline guard/engage 모드 재평가(s)
  holdMax: 12,                 // 받아치기 팀이 교전 없이 기다리는 최대 시간(s)
  reachMargin: 0.5,            // 팔 길이 비교 여유(m)
  spacingMin: 2.5, spacingVsCathyE: 3.0, spacingMax: 6.0,  // 아군 간격(m)
  frontOffset: [1.5, 2.5], carryOffset: [-3.0, -1.5], midOffset: [-1.0, -0.5],
  peelDist: 3.5,               // 적 근접이 아군 원딜에 이 거리 안이면 필
  guardDist: 3.5,              // frontline-원딜 유지 거리(캐시 Q 4m 이내)
  isolateDist: 5.0,            // 적이 자기 팀 중심에서 이만큼 떨어지면 '고립'
  edgeLimit: 12.0,             // 원딜이 투기장 중심에서 넘지 말 반지름(m), 투기장 r≈17
  chaseDist: 8.0, chaseTime: 3.0,
  lowHp: { ranged: 0.30, melee: 0.25 },
  pingpong: { dmgWindow: 1.5, dmgPct: 0.15, takeoverHp: 0.60 },
  focus: { hold: 1.2, switchMargin: 15, playerFocusTtl: 2.0 },
  followReact: { easy: 0.6, normal: 0.35, hard: 0.2 },
  ccChainLead: 0.15,           // 기절 종료 몇 초 전에 다음 CC
  flankUnseen: 5.0,            // 적 암살자 미확인 시간 → 플랭크 가정
  regroupBack: 4.0, restAfterRegroup: [2, 4],
  tradeAccept: { hpSumRatio: 1.0, hpSumRatioCarry: 1.3 },
  engageScore: 3, retreatScore: 1, // 4항목 체크리스트
}
```
