## 0. 핵심 요약

- 현재 실험체 **91명** (91번째 **세레스**가 2026-10-01 출시). 출시 번호는 이터널 리턴 출시 순서(나무위키 정렬 기준).
- 공식 역할군 **6종**: 탱커 / 전사 / 암살자 / 스킬 딜러 / 원거리 딜러 / 지원가. 실험체당 최대 2개 배정.
  - 과거(역할군 도입 전) 커뮤니티 비공식 분류는 딜러 / 브루저 / 탱커 / 서포터 4종이며 지금도 많이 쓰인다. "브루저" ≈ 공식 "전사".
- 무기군 **23종**. "장갑"은 공식 명칭이 **글러브**. 실험체별 장착 가능한 무기가 정해져 있으며, **마커스 이후 신규 실험체는 모두 단일 무기**.
- 무기 스킬(D키, 전술 스킬 F키와 교체 가능)은 무기 숙련도 5/10/15 레벨에 1/2/3레벨로 자동 상승하고 **쿨다운 감소 스탯의 영향을 받지 않음**.
- 모드: 루미아 섬(3인 스쿼드 랭크/일반), 코발트 프로토콜(4:4), 론 울프(솔로) — 실험체마다 모드별 피해 보정이 있음.

- **필(아군 보호)**: 퓨어 탱커(알론소·일레븐 등의 CC 연계), 지원가, 아야 R(공포) 같은 자체 필.
- **후진입 마무리**: 재키(처치 관여 시 E 초기화, R 지속 연장) — 아군이 깔아둔 판에 들어가 정리.
- **원딜 커팅**: 다니엘(W 표식 → R 무적 진입), 누킹형 스킬 딜러.

### 3.2 흔한 팀 조합 (3인 스쿼드)

- 가장 무난한 조합(가이드 문서): **탱커 + 근거리 딜러 + 원거리 딜러**, 또는 **근거리 딜러 2 + 원거리 딜러**. (코발트 4인 기준으로는 탱커+근딜+평타 원딜+스킬 원딜)
- 순수 서포터는 최대 1명. 탱커 2 / 서포터 2처럼 딜이 부족한 조합, 근·원거리 비율이 한쪽으로 쏠린 조합은 지양.
- **3근 조합**: 전사 3명 — 후반을 포기하고 초중반 교전으로 스노우볼.
- **탱커 + 원딜 + 암살자**: 다니엘 문서가 권장하는 "탱커 1, 원딜 1" 틀 — 암살자가 적 원딜을 자르는 동안 버티는 구도. 다니엘은 퓨어 서포터와는 상성 나쁨.
- 실험체 문서 권장 시너지 예: 캐시 ↔ 알론소·라우라(적을 모아줘 수쳐 각) / 재키 ↔ 테오도르(묶기+가속 장판)·엘레나(선진입 난전) / 현우 ↔ 레니(스프링 트랩으로 이니시 보완) / 아야(권총·저격) ↔ 알론소·일레븐(긴 CC로 W 고정 사격 각), 돌격 소총 아야 ↔ 다르코(필).

## 4. 시뮬레이터 관련 실험체 상세 (캐시 · 다니엘 · 재키 · 현우 · 아야)

공통 사항
- 일반 스킬 Q/W/E는 5레벨, R과 패시브는 3레벨. 궁극기(R)는 실험체 레벨 6부터 습득 가능(나무위키 쌍절곤 문서 "궁극기가 열리는 6랩").
- 쿨다운은 쿨감 적용 전 기본값(무기 스킬·아야 패시브는 쿨감 무시). 최종 CD = 기본 CD × 100 / (100 + 쿨감 합계) (가이드 문서 공식).

- 출시일은 최근 3명 외에는 미기재(출시 "순서"만 정리). 공식 실험체 DB(game.naver.com 라운지)는 JS 렌더링이라 미확인.
- eternalreturn.fandom.com은 접근 차단(402)으로 교차 검증하지 못함.
- 모드별 피해 보정(코발트·론 울프)은 각 실험체 문서 표에 있으나 루미아 섬(랭크) 보정은 별도 표기가 없음.
