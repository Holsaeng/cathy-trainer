# 플레이어 조작용 원딜 4인 스킬 상세 — 아야 · 리오 · 나딘 · 카티야

조사일 2026-10-11. 기준은 **시즌 12 "세일링" 12.5 패치(2026-10-01) + 12.5a/12.5b 핫픽스**입니다. 12.5a·12.5b에는 이 4명과 이들이 쓰는 무기 관련 변경이 없습니다.
목적은 시뮬레이터의 AI 원딜 4명(`CONFIG.rangedMotifs` / `CONFIG.rangedKits`, `src/4_b_kits.js`)을 **플레이어가 직접 조작하는 캐릭터**로 만들 때 필요한 스킬 동작 규칙을 정리하는 것입니다.

표기 규칙
- 레벨별 수치는 `a/b/c/…` 순서입니다. Q·W·E는 5레벨, P·R은 3레벨, 무기 스킬(D)은 숙련도 5/10/15에 해당하는 1~3레벨입니다.
- 계수 약어: **공** = 공격력, **추공** = 추가 공격력, **스증** = 스킬 증폭, **기공증** = 기본 공격 증폭.
- ⚠ = 출처끼리 수치가 다르거나 확인하지 못한 값, 또는 추정값.
- 툴팁 문장은 옮기지 않고 요약했습니다(수치는 그대로 적음).

## 2. 공통 사항 (플레이어 조작 구현에 필요한 규칙)

- **무기 스킬(D) 쿨다운은 쿨감의 영향을 받지 않습니다**([닥지지] 툴팁 "쿨다운 고정"). 리오 Q(0.8초)와 아야 P도 같습니다.
- 12.0부터 **무기 스킬도 실험체 스킬의 '스킬 사용/적중' 조건에 포함**됩니다([공식 12.0-2]). 예를 들어 리오의 카이츄 중첩은 곡사가 적중해도 쌓이고, 아야 P의 쿨 감소도 무기 스킬로 받습니다(아야 P는 원래 '공격할 때마다').
- 곡사는 **다른 스킬과 동시에 사용할 수 없습니다**([공식 12.0-2]). 시전 중에는 다른 키 입력을 막아야 합니다.
- 원거리 평타는 모두 유도 투사체입니다(대상 지정). 시뮬레이터의 `home: p` 방식이 맞습니다.

### CONFIG와 비교
- 12.5 상향(Q 1발째 110%, W 공 55%)은 반영되어 있습니다.
- Q는 `windup 0.35`를 공속으로 나누는 구현과 출처의 설명이 같은 방향입니다. 정확한 시전 시간은 ⚠ 출처 없음.
- W 진행 중 평타 금지(`noAA`)는 출처에 명시가 없습니다 ⚠. 연사 모션이므로 평타 불가로 두는 것이 무난합니다.
- D의 '스증 1%' 표기는 '스증 1당 이속 +1%p'인지 '스증의 1%'인지 출처에서 구분되지 않습니다 ⚠. 현재 미구현이며 영향은 작습니다.

### 플레이어 조작 구현 메모
- **Q**: 커서 아래(또는 커서에서 가장 가까운) 적을 대상으로 지정합니다. 사거리 6.5m 밖이면 대상에게 다가간 뒤 시전하는 방식(LoL식 이동 후 시전)이 실제 게임과 같습니다. 시전하는 동안 이동 입력은 버퍼에 담아 두었다가 2발째 발사 뒤 적용합니다.
- **W**: 누른 순간의 '아야→커서' 방향으로 고정합니다. 연사 중에는 우클릭 이동을 그대로 허용하고, 다시 W를 누르면 중단합니다. 남은 탄 수는 시전 시점의 추가 공속으로 정합니다.
- **E**: 커서 방향으로 4m 대시합니다(커서가 4m보다 가까워도 4m). 벽 너머 착지 지점이 벽 안이면 `Geo.pushOut`으로 밖으로 밀어냅니다. 사용 즉시 Q·W 남은 쿨에 (1−감소율)을 곱합니다.
- **R**: 자기 중심 즉시 시전, 0.66초 동안 이동을 잠급니다. 실제 게임에서는 시전 직후 이동 명령이 남아 있으면 W가 빗나가므로 'S(정지)→R→W' 입력이 정석입니다. S키(정지)를 구현해 두면 좋습니다.
- **D**: 즉발로 1초 이속 버프를 걸고 평타 입력을 막습니다(스킬 입력은 허용). 끝난 뒤 평타 2회에 공속 +70%를 줍니다. 평타 후딜을 끊고 거리를 벌리는 용도입니다.
- **P**: 피격 시 자동 발동. HUD에 쿨 아이콘을 두고, 평타·스킬이 맞을 때마다 1초씩 줄입니다.
- 흔한 콤보([나무-아야]): `평 → Q → 평 → W(무빙 카이팅) → E(Q·W 쿨 회수) → Q → W` 사이클. 근접이 붙으면 `S → R → W`. 위급하면 `E`로 벽 넘기, 이어서 `D`로 이탈한 뒤 강화 평타 2회.
