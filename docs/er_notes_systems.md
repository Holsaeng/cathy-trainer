## 1. 게임 개요

### 1.1 기본 정보
- 개발: 님블뉴런(넵튠 자회사). 한국산 **쿼터뷰 배틀로얄 + MOBA**(나무위키 장르 표기: "쿼터뷰 - 배틀로얄, MOBA").
- 얼리 액세스 2020-10-14, 정식 출시 2023-07-20. 엔진 Unity. 원작은 모바일 '블랙서바이벌'.
- 핵심 루프: 파밍(재료 수집) → 장비/음식 제작 → 야생동물 사냥·오브젝트 쟁탈로 성장 → 다른 팀 처치 → 최후의 1팀.

### 1.2 매치 구조 (루미아 섬 — 일반/랭크)
- **3인 1팀 × 최대 8팀 = 24명**. 캐릭터/루트 선택 단계에서 1팀이 닷지하면 7팀 21명으로 진행, 2팀이 닷지하면 매치 무효.
- 같은 팀 내 캐릭터 중복 선택 불가. 밴 시스템 없음.
- 준비 시간 총 60초: 캐릭터는 40초 이후 변경 불가, 나머지(시작 무기·시작 지역·루트·특성·전술 스킬)는 60초 동안 변경 가능. 이후 5초간 조작 불가 → 로딩.
- 시작 지역은 루트의 1번 지역이 기본이나, 섬의 19개 지역 중 직접 골라 바꿀 수 있음(⚠ 팬덤: 전체 21개 지역, 그 중 20개가 일반 진입 가능 — 연구소·바지선 포함 여부에 따른 차이로 보임).
- 시작 시 대부분의 실험체는 스킬 포인트 1개로 Q/W/E 중 하나를 배움.
- 시작 크레딧 15. (팬덤: 빵·물 1개씩, 셔츠·러닝화 착용, 잠시 이동속도 120% 버프 — 팬덤 단독 정보)

### 1.3 승리 조건 / 게임 종료
- 최후까지 생존한 1팀 승리.
- 2일차 이후 팀 전멸 시 탈락("사출"). 마지막 생존 팀원의 체력이 0이 되면 빈사 상태 팀원도 모두 자동 사망.
- **탈출**: 3일차 낮부터 가능(8.0 패치에서 4일차 → 3일차로 완화). 키오스크에서 '루프 카드키 - RED'(100크레딧) 구매 → 팀원 과반(2명) 찬성 → 카드키 사용 → 5초 대기 후 잠수함으로 탈출. 조건: 팀원 중 최소 1명이 (급속 재생 종료 후) 사망 상태, 잔여 팀 2팀 이하이거나 임시 안전지대 활성화 시 불가, 최대 2팀까지. 랭크에서 탈출 시 고정 +10점.

### 1.4 낮/밤 사이클과 페이즈 (나무위키 가이드 기준)

| | 2일차 낮 | 2분 10초 (130초) |

| | 5일차 낮 / 밤 | 80초 / 80초 |

| | 8일차 낮 | 150초 |

- 총 약 27분 20초(500+680+460초).
- ⚠ 8.0 패치노트에는 "7일차 낮 60→40초, 7일차 밤 80→150초" 변경이 있고, 팬덤은 "7일차 밤에 최종 안전지대"라고 서술해 나무위키(8일차 낮까지)와 구조가 다르다. 시즌별로 엔드게임 구조가 자주 바뀌었으므로 최신 수치는 나무위키 가이드 표를 기준으로 했다.
- 위클라인 첫 생성: 11분 55초(4일차 밤) — 나무위키 루미아 섬.

### 1.5 부활 규칙 (오프닝 = 1~2일차)
- 2일차까지는 팀원 1명이라도 살아 있으면 빈사/사망 시 **부활 타이머**가 생김.
  - 나무위키 레벨별 타이머: 1~6레벨 3~8초, 7레벨 10초, 8~11레벨 25~30초, 12레벨 35초, 13레벨 이상 40초.
  - 공식 1.0.0 표: Lv1~3 3초, Lv4 4초, Lv5 6초, Lv6 8초, Lv7 18초, Lv8~9 25초, Lv10~11 30초, Lv12 35초, Lv13~20 40초. ⚠ 7레벨 값이 다름(나무위키 10초 vs 1.0.0 18초 — 이후 패치로 바뀌었을 수 있음).
  - 타이머 종료 후 30초 안에 부활 지역 선택 → 3초 대기 → **체력 55%로 부활**(나무위키). ⚠ 팬덤은 40%라고 서술(구버전 정보로 추정).
  - 폭사 후 부활 시 금지구역 타이머 10초 부여.
- **1일차**: 팀이 전멸해도 일정 시간 후 전원 부활(부활 시간이 동기화됨). 2일차부터 전멸 = 탈락. 단, 1일차에 죽어 부활 대기 중인 팀원이 있으면 사출되지 않음. 일반 대전은 2일차 낮까지 전멸 방지가 연장.
- **미들 게임(3일차~)**: 자동 부활 종료. 키오스크에서 **200크레딧**(병원 키오스크는 150) 지불로 부활, 3일차 낮~4일차 밤까지만. 크레딧이 부족하면 부활 대상의 크레딧으로 충당. 공식 1.0.0: 키오스크 부활 캐스팅 2초. ⚠ 팬덤은 250크레딧(구버전).
- 5일차 낮부터 키오스크 부활 종료 → LUMI(로봇 상점)에서만 1명당 200크레딧으로 부활 가능. LUMI는 6일차 밤에 섬을 떠남.
- 엔드 게임: 임시 안전지대 페이즈에서 승리하거나 상대 팀이 없으면 사망한 아군 부활 가능.
- 전투 연구실(차원의 틈) 입장 시 죽어 있는 아군 즉시 부활.

### 1.6 빈사 상태와 선언 효과
- 체력 0 → 빈사: 체력 400, 이동속도 1로 감소, 받는 피해 50%+(레벨×1.5)% 감소, 초당 체력 1 감소. 빈사 타이머가 0이 되면 사망.
  - ⚠ 공식 1.0.0은 "받는 피해 감소 40% + 레벨²×0.09%", 이동속도 0.5→1, 소생 시 체력 50%→25%로 기재. 현재값은 나무위키 수치이나 공식 최신값과 다를 수 있음.
- 빈사 처치 시 처치한 팀 전원에게 **승전보**: 반경 28m 팀원 최대 체력 20% 회복 + 모든 스킬 쿨다운 20% 감소.
- 빈사 스킬: Q 분열 폭발(4초 후 자폭, 150+대상 현재 체력 20% 고정 피해, 쿨 10초; 자폭 사망 시 적에게 승전보 없음), W 집념(3초 이속 +100%, 쿨 4초), R 자가 제세동(20초 정신 집중 후 최대 체력 25%로 소생, 쿨 20초).
- 선언 효과: BREAK / TERMINATE(2.5초 이속 +1, 빈사 아군 소생 3초 단축, 잃은 체력 50% 즉시 회복), CLUTCH(혼자 생존 상태에서 전멸시킴 — 이속 +150%), CHECKMATE(최종 승리 안내).

### 1.7 금지 구역 / 안전 지대
- 시간 경과마다 지역이 금지 구역으로 지정(지도: 노랑 = 다음 금지 구역, 빨강 = 금지 구역, 흰 테두리 깜빡임 = 다음 일차 해제). 최종적으로 섬 전체가 금지 구역이 됨.
- **폭발 타이머**: 시작 20초, 처치 관여 시 +7초, 알파/오메가 처치 시 +2초, 최대 30초. 0이 되면 빈사 여부와 무관하게 즉사. ⚠ 팬덤: 킬당 +5초.
- 경직(아티팩트 전술 스킬)은 금지 구역 카운트가 줄지 않는 유일한 수단.
- 연구소는 4일차 밤부터 영구 금지 구역.
- 금지 구역 해제 시 그 지역 야생동물이 즉시 리스폰.
- **6일차 밤**: 폭발 타이머 +10초(상한 무시), 남은 가장자리 두 지역이 **임시 안전지대**로 지정되고 크로노 스피어 배치. 7일차 낮에 활성화되며 그 외 지역에 있는 실험체는 즉사.
  - 임시 안전지대 진행: 반경 30m 생성(5초 대기) → 20초에 걸쳐 10m로 축소 → 10초 이동 대기 → 이동 → 15초에 걸쳐 4m로 축소 → 40초 유지 → 5초에 걸쳐 소멸.
  - 6일차 밤 시점 2팀만 남고 서로 다른 지역에 있으면 임시 안전지대 페이즈 생략.
- **최종 안전지대**: 7일차 밤에 두 지역 사이 지역의 크로노 스피어가 반경 30m 안전 지대 생성 → 8일차 낮: 20초간 14m로 축소 → 10초 대기 → 이동 → 15초간 5m로 축소 → 40초 대기 후 소멸. 이후엔 폭발 타이머가 많이 남은 쪽이 유리.

### 1.8 모드
- **일반 대전**: 3인 스쿼드, 8팀, 루미아 섬. 코어 모드.
- **랭크 대전**: 스쿼드 기반(정식 출시 후 솔로/듀오 랭크 삭제).
- **코발트 프로토콜**(2022-06-09 추가): **4 vs 4** 점령전. 양 팀 라이프 포인트 **40**에서 시작. 실험체 처치, 증폭 장치 40초 점령 유지(상대 LP −1), 감마 처치(상대 LP −5)로 상대 LP를 0으로 만들면 승리.
  - 파밍/제작 없음. 준비 단계에서 영웅 장비 지급, 크레딧으로 합성기에서 완제품 구매(장비 추가 보급 50크레딧 = 전설 장비 선택, 3페이즈부터 100크레딧으로 초월 장비).
  - 크레딧: 시간 경과 1.4초당 1, 처치 4/관여 2, 드론 2, 오메가 20(팀 10), 감마 40(팀 20), 점령 5 등.
  - 특성은 핵심 특성 1개만, 인퓨전(페이즈마다 1포인트, 최대 3개)으로 보조 효과. 전용 전술 스킬(부착/추적, 힘껏펀치, 임펄스, 메테오, 쇠약, 중력장, 롤링썬더).
  - 페이즈: 0(준비) → 1(드론·증폭 장치) → 2(오메가 등장) → 3(감마 등장, 초월 장비, 상황실 앞 증폭 장치 비활성화) → 서든 데스(터렛 비활성, 30초 안에 먼저 1킬한 팀 승리).
  - 맵: 상황실(리스폰·상점·자율 방어 터렛), 증폭 장치 3개(양 진영 앞 + 중앙), 힐팩, 점프 패들, 하늘나리, 스텔스 필드(=부쉬).
- **론 울프**(이벤트 모드, 구 솔로 모드 부활): 최대 **18명 개인전**, 재생성 키트 2개로 시작(= 최대 3목숨), 자동 부활·탈출 없음, 모든 실험체 받는 회복 20% 감소, 전체 최대 18분(1일차 낮 120초, 밤 100초, 2일차 낮 110초 …). 아시아1 서버 20:00~24:00(KST)에만 매칭(사용자 설정 대전은 무제한).
- 기타: 유니온 대전(BETA, 3~4인 팀 대항전), 튜토리얼, 훈련(연습 모드·AI 대전), 사용자 설정 대전.

### 1.9 랭크 시스템 기초
- 참가 조건: 계정 레벨 30 이상, 휴대폰 인증, 실험체 3개 이상 보유. 신규 실험체는 출시 직후(나무위키: 5일/다음 주 화요일까지) 사용 제한.
- 티어(10단계): 아이언 → 브론즈 → 실버 → 골드 → 플래티넘 → 다이아몬드 → 메테오라이트 → 미스릴 → 데미갓 → 이터니티. 아이언~메테오라이트는 IV~I 디비전.
- **입장료(RP)**를 먼저 차감하고, 최종 순위·킬(처치 관여)·탈출 여부로 RP 획득. 예: 아이언 입장료 0(IV 0~149 RP …), 브론즈 IV 600~799 RP 입장료 10, 브론즈 I 16, 실버 IV(1400~) 18 …
- 승급 시 +50 RP 보너스, 강등 시 −50 RP 추가 차감.
- 데미갓 = 상위 1000위, 이터니티 = 상위 300위(상대 순위제).
- 닷지 페널티: 1회 2분/−5점, 2회 5분/−15점, 3회+ 20분/−30점(12시간 후 초기화).
- 탈주: 120초(5일차부터 90초) 내 재접속 실패 시 영구 탈주. 남은 팀원은 항복 투표 가능, 입장료보다 적게 얻었으면 입장료 면제.
- 메테오라이트 이상 휴면 강등. 시즌 종료 시 소프트 리셋.
- 갬빗(12.4~12.7 시범): 솔로 매칭·다이아 이하, RP 획득·입장료 2배(전원 선언 시 3배).

## 2. 캐릭터 능력치와 피해 공식

### 2.1 능력치 정의 (나무위키 가이드 3.2.1)
- **체력**: 생명력. 레벨업 시 증가.
- **방어력**: 받는 기본 공격·스킬 피해 감소.
- **공격력**: 기본 공격 피해이자 평타 기반 실험체의 주 스킬 계수.
- **스킬 증폭**: 스킬 증폭 기반 실험체의 주 스킬 계수.
- **맞춤형 능력치(적응형)**: 추가 공격력/스킬 증폭 중 높은 쪽으로 적용. 공격력은 그대로, 스킬 증폭은 2배(1:2). 예: 맞춤형 30 = 공격력 30 또는 스킬 증폭 60 (공식 1.0.0).
- **기본 공격 증폭**: 기본 공격 피해 증가.
- **공격 속도**: 초당 기본 공격 횟수. ⚠ 팬덤: 최대치 2.5(나무위키에서 확인 못함). 특성 '아드레날린'(최대 중첩)·'액셀러레이터'가 공격 속도 상한을 무시함 → 상한 자체는 존재. 8.0: 공속 1 초과 시 평타 투사체 속도 증가는 최대 50%까지로 캡.
- **쿨다운 감소**: 아래 2.3 참조. 별도로 궁극기 쿨감, 전술 스킬 쿨감 스탯 존재.
- **치명타 확률**: 기본 공격이 **175%** 피해를 줄 확률. '치명타 피해 증가'로 배율 상승 가능. 기본 치명타 확률 0(팬덤).
  - ⚠ 배율 변천: 공식 1.0.0에서 "기본 치명타 배율 165 → 160%"로 하향. 현재 나무위키 본문·팬덤은 175%, 나무위키 각주의 구 공식은 0.65(=165%). 즉 시기별로 160/165/175%가 혼재 — 현재값은 175%로 판단하나 패치마다 확인 필요.
- **이동 속도**: 초당 이동 거리(m/s). 실험체마다 기본값 상이. 강풍(서브 날씨) 시 기본 이속 증가(나무위키 현재 3%, 1.22 도입 당시 5% ⚠).
- **시야**: 시야 반경(m). 아래 2.2 참조.
- **기본 공격 사거리**: 실험체 기본값 + 무기군 사거리.
- **피해 감소**: 기본 공격 피해 감소 / 치명타 피해 감소 / 스킬 피해 감소로 분류.
- **방어 관통**: 고정 관통과 %관통 두 종류.
- **모든 피해 흡혈 / 생명력 흡수**: 각각 모든 피해 / 기본 공격 피해의 일정 비율 회복. 광역 피해는 50%, 야생동물 대상은 60%만 적용.
- **이동 속도 감소 효과 감소**(둔화 저항): 둔화 지속 시간 감소.
- **방해 효과 저항**(Tenacity): 기절·둔화·속박 등의 지속 시간 감소. 붙잡힘·에어본·제압에는 무효. 팬덤: [고유] 옵션이라 중첩되지 않음.
- **고유 자원**: 일부 실험체 전용(이바의 바이탈 포스, 에키온의 VF 게이지 등).
- **스태미나(SP, 기력)**: 스킬 사용 등에 쓰이는 자원(대부분 실험체). 8.0부터 제작·오브젝트 상호작용 등에는 소모하지 않음. 휴식으로 회복(아래 4.2). 세부 소모량은 실험체별로 다름.

### 2.2 시야 수치
- 기본 시야 **낮 8.5m** (공식 1.0.0: 8m → 8.5m로 조정, 탐색 숙련도 시야 보너스 삭제와 함께).
- 팬덤: 휴식 중 낮 7.5m. **밤 시작 시 3.4m(휴식 3m)로 급감 후 점차 6.4m(휴식 6m)까지 회복**, 새 날이 되면 정상화. 카메라 시야도 밤에 30% 감소.
- 8.6 패치(2025-09-18): "밤으로 인한 시야 감소 효과가 5% 줄어들어" 밤 시야가 늘어남 → ⚠ 팬덤의 3.4m/6.4m는 8.6 이전 값일 가능성이 있음(정확한 현재 밤 시야 m 값은 미확인).
- 날씨: 쾌청 시 기본 시야 8.5 → 10m(1.22 도입 당시; 나무위키 현재 서술은 "+1.5m"로 동일 결과). 모래바람은 1.22 도입 당시 8.5 → 7m였으나, 나무위키 현재 서술에는 시야 감소가 없음 ⚠.
- VLS 하강 중(고도 30m 이하) 시야 10.5m(팬덤).

### 2.3 쿨다운 감소 공식 (8.0 패치에서 변경)
- 구 공식: 최종 쿨다운 = 기본 쿨다운 × (100 − 쿨감 합계)/100, **최대 쿨감 30% 제한**.
- **현행(8.0~)**: 최종 쿨다운 = 기본 쿨다운 × 100 / (100 + 쿨감 합계) — 방어력 공식과 같은 점감형, **상한 없음**. 쿨감 수치는 % 없이 표기(예: 50 → 33% 감소).
- 무기 스킬·전술 스킬은 대부분 "쿨다운 고정"(일반 쿨감 영향 없음). 전술 스킬은 '전술 스킬 쿨다운 감소' 스탯으로만 감소.

### 2.4 피해 공식 (나무위키 가이드 3.2.2 — 편집자가 가독성 위해 재구성, 일부 용어는 비공식)
공통: 추가 피해(%)와 스킬 증폭(%)은 증폭률을 0.1 미만으로 낮출 수 없다.

**기본 공격 피해**
1. 대상의 적용 방어력 = (대상 방어력 × (1 − 방어 관통%)) − 고정 방어 관통
2. 공격력 계산 피해 = 공격력 × 100 / (100 + 적용 방어력) × (1 + [치명타 시] (0.75 + 치명타 피해 증가%))
3. 피해 증가 = 공격력 계산 피해 × (피해 증가% − 대상 피해 감소%)
4. 기본 공격(%) = 피해 증가 × (1 + 기본 공격 증폭% − 대상 기본 공격 피해 감소%)
5. 최종 피해 = (기본 공격(%) × 최종 피해 추가%) + 최종 피해 추가(고정)
6. 모드 보정 = 최종 피해 × (모드별 주는 피해 보정% − 대상 모드별 받는 피해 보정%)

**스킬 피해**
1. 스킬 기본 피해 = 스킬에 정의된 피해 × 100 / (100 + 적용 방어력)
2. 피해 증가 = 스킬 기본 피해 × (1 + 피해 증가% − 대상 피해 감소%)
3. 스킬 피해 감소 적용 = 피해 증가 × (1 − 대상 스킬 피해 감소%)
4. 최종 피해 = (위 값 × 최종 피해 증가%) + 최종 피해 추가
5. 모드 보정 동일.

**고정 피해**: 모드별 피해 증감만 적용 → 고정 피해 × (1 + 모드별 주는 피해 증가% − 모드별 받는 피해 감소%).

- 핵심: 방어력 감소 공식은 **100/(100+방어력)** 형태(방어력 100이면 받는 피해 50%).
- ⚠ 공식 3·5단계 표기가 나무위키 원문 그대로이며(“피해 증가% − 피해 감소%”에 1+가 빠진 듯한 부분 등) 일부 오기 가능성이 있음. 스킬에 정의된 피해는 "기본 피해 + 스킬 증폭/공격력 계수"를 의미.

### 2.5 치유 감소 / 회복 관련
- 치유 감소는 아이템·특성·환경으로 부여되며, **중첩되지 않고 가장 높은 수치만 적용**(1.22 패치노트, 모래바람 설명).
- 예시 수치: 특성 '상흔' 1중첩 10%(최대 2중첩 20%), 위클라인 '신경 가스 살포' 40%, 1.22 모래바람 전투 중 20%, 론 울프 모드 전체 받는 회복 −20%, 들개 '깨물기' 치유 감소. 치유 감소 옵션 장비는 주로 운석·생명의 나무 재료 장비(나무위키 특성 문서).
- 나무위키/공식 문구에 "약한 치유 감소"라는 등급 표현이 있으나 강/약 단계의 정확한 % 정의는 확인하지 못함 ⚠.
- 회복 관련 스탯: 주는 회복 증가(Healing Power), 받는 회복 증가(팬덤). 흡혈류에는 주는 회복 증가가 적용되지 않음(팬덤).

### 2.6 보호막
- 보호막을 직접 다루는 공통 규칙 문서는 찾지 못함 ⚠. 확인된 사례: 전술 스킬 '초월'(3초 보호막, 추가 체력 계수), 코발트 '기원'(삭제), 일부 아이템(비전투 5초 후 보호막 획득 등, 1.22 패치노트). 피해는 보호막이 먼저 흡수하는 일반적 구조로 보임.

## 3. 군중 제어(CC) / 상태 정의 (나무위키 가이드 3.2.3)

> 걸어서 이동하는 상태(공포·매혹·도발)는 실험체가 직접 걷는 것이므로, 이동 불가 상태와 겹치면 움직이지 않는다.

| 상태 | 정의 |
|---|---|
| 경직 | 피해를 받지 않고 대상 지정 불가, 대신 아무 행동 불가. 금지 구역 카운트가 줄지 않음. 점프 패들로 이동은 가능. (아티팩트 전술 스킬) |
| 고정(Grounded) | 이동은 가능하나 이동 기술 사용 불가 |
| 공포 | 시전자 반대 방향으로 걸어서 이동, 스킬 사용 불가 |
| 기절 | 이동·평타·스킬 불가 |
| 도발 | 시전자에게 강제 기본 공격(사거리 밖이면 걸어서 접근), 스킬 불가 |
| 이동 속도 감소(둔화) | 비율만큼 이속 감소, 일정 하한 존재. 이름표 변화 없음 |
| 공격 속도 감소 | 비율만큼 공속 감소(공속 고정 캐릭터 제외) |
| 매혹 | 시전자 위치로 걸어감, 평타·스킬 불가 |
| 졸음-수면 | 졸음 중 이속 감소 → 수면(이동·평타·스킬 불가). 피격 시 추가 피해 후 해제 |
| 무장 해제 | 기본 공격 불가 — 시즌 7 유키 리워크로 **삭제됨** |
| 대상 지정 불가 | 타깃팅 불가, 이미 적용된 효과 외 모든 효과 무시. 이름표·캐릭터 흐려짐 |
| 무적 | 피해를 입지 않음. 이름표 흰 테두리, 레벨 표시가 방패 모양 |
| 위장 | 일정 범위 밖의 상대에게 관측되지 않음. 범위 내 절대 시야가 있으면 감지 |
| 은신 | 상대 시야에서 사라짐. 절대 시야가 있으면 감지 |
| 변이(Polymorph) | 평타·스킬 불가, 이속 크게 감소, 다른 물체로 변함 |
| 붙잡힘 | 특정 위치로 강제 이동, 평타·스킬 불가 |
| 속박(Root) | 이동 불가, 이동이 포함된 기술 외에는 사용 가능 |
| 시야 차단 | 일정 범위 밖 시야 없음. 카메라·드론·아군 시야·본인 시야 확보 능력 모두 무효 |
| 실명 | 기본 공격이 모두 빗나감 |
| 회피 | 자신에게 오는 기본 공격이 모두 빗나감(버프) |
| 에어본 | 공중에 떠 이동·공격·스킬 불가. 제자리 띄우기, **밀치기(넉백)**, 끌어당기기, 넘기기 방식. **방해 효과 저항 영향 없음**. 넉백은 원래 별도 판정이었으나 **시즌 11 이후 에어본으로 편입** |
| 정신 집중(채널링) | 특정 스킬 시전 중 상태. 경직·기절·공포·도발·매혹·변이·붙잡힘·에어본·제압·춤·침묵으로 취소, 이동 포함 정신 집중은 속박으로도 끊김 |
| 제압(Suppression) | 이동·평타·스킬 불가, 시전 중인 이동기·돌진 즉시 중지 |
| 춤 | 평타·스킬 불가, 이속 2.5 고정(고정·둔화로 판정), 춤 모션 |
| 침묵 | 스킬 사용 불가 |
| 정신 이상(Insane) | 행동 불가, 근처 대상을 강제 공격(아군 우선) |
| 이동 방해 면역 | 공포·기절·넉백·도발·둔화·매혹·속박·에어본·제압·춤 무시 |
| 저지 불가(Unstoppable) | 모든 CC 무시. 저지 불가 종료 시점까지 남은 CC는 그때 발동. 유키 R 2타 같은 디버프는 무시 못함 |
| 모든 방해 면역 | 모든 CC 무시(유키 R 2타류 디버프는 무시 못함) |
| 해로운 효과 면역 | 모든 CC + 디버프 무시 |
| 해로운 효과 제거 | 모든 CC + 디버프 제거 |
| 이동 속도 감소 면역 | (8.0 추가) 부여 시 남은 둔화 제거, 지속 중 둔화 면역 (예: 이바 E) |

## 4. 전투 메커니즘

### 4.1 전투 상태
- 피해를 주고받으면 전투 상태가 되며, 비전투 상태에서만 적용되는 효과가 다수(휴식 추가 회복, 제작 숙련도의 비전투 체력 재생, 일부 아이템의 '비전투 5초 후 보호막' 등).
- 전투 상태 유지 시간(몇 초 후 해제되는지)의 정확한 공통 수치는 확인하지 못함 ⚠.

### 4.2 휴식 (X 키)
> **✅ 현재 규칙 (시즌 12, 공식 12.0 패치노트 2026-08-06 직접 확인 — 아래 구 규칙보다 우선)**
> - 전투 상태와 무관하게 언제든 시작 가능(비전투 제한 삭제).
> - 3단계 **캐스팅**: 각 단계가 *완료될 때* 회복이 한 번에 적용. 1단계 3초 → 최대 체력 15% / 2단계 3초 → 15% / 3단계 4초 → 50%. 도중 취소 시 진행 중이던 단계 회복은 없음.
> - 단계 종료 0.25초 이내에 이동 입력 시 그 단계 회복을 마친 뒤 이동.
> - 모든 단계 완료 후에도 휴식 모션은 유지(추가 회복 언급 없음).
> - 취소: X 재입력·이동 명령·피해·군중 제어(또는 아군 강제 취소 스킬). 취소 시 1초 재사용 대기.
> - UI: 휴식 중 체력바 테두리 강조 + 캐스팅 바 + 예상 회복량 표시(적에게도 보임).
> - 패치노트에는 기력 회복량·비전투 추가 회복이 언급되지 않음 ⚠.
> - 출처: https://playeternalreturn.com/posts/news/3742
>
> 아래는 시즌 12 이전(나무위키 가이드에 남아 있는) 구 규칙.

- 자리에 앉아 체력/기력(스태미나) 회복. 휴식 중 **시야 감소**(팬덤: 낮 8.5→7.5m, 밤 최소 3m/최대 6m).
- 종료 후 **1초 쿨다운**.
- **비전투 상태**일 때 0.5초마다 최대 체력/기력의 2%를 추가 회복.
- 단계별 회복:
  - 1단계: 3초에 걸쳐 최대 체력 10%, 최대 기력 20%
  - 2단계: 3초에 걸쳐 최대 체력 15%, 최대 기력 25%
  - 3단계: 4초에 걸쳐 최대 체력·기력 30%
- 직접 공격(지속 피해·아이템 피해 제외)이나 방해 효과를 받으면 취소.

### 4.3 스태미나(기력)
- 스킬 사용 자원(대부분 실험체). 8.0 패치부터 **제작·오브젝트 상호작용 등에는 스태미나 소모 없음**.

### 4.6 숙련도 (나무위키 가이드 4.7)

- **제작**: 레벨당 비전투 체력 재생 +10%.

- 각 지역에는 상자·자동차·자판기·그루터기 등 탐색 오브젝트, 채집물(돌멩이·나뭇가지·감자·물·꽃·대구 낚시터 등), 모닥불(요리), 일부 지역에 키오스크·하이퍼루프 존재.

### 5.2 이동: 하이퍼루프 / VLS
- **하이퍼루프**: 작동 후 지역 선택 → **3초** 후 해당 지역 4개 스타팅 포인트 중 무작위로 이동(아군 지정 시 그 위치). 도착 후 **2초간 대상 지정 불가 + 이속 크게 감소 + 평타·스킬 불가**(제작·이동은 가능), 도착 지점 근처 적에게 도착 핑.
  - 1일차 낮에는 작동 중 방해 효과 면역. 2일차 낮 직후 위성 레이더(전체 위치 일시 공개) 작동 시 하이퍼루프 사용 불가 — 나무위키 8초, 공식 1.0.0 10초 ⚠.
  - 하이퍼루프 지역(팬덤): 주유소, 숲, 학교, 절, 개울, 병원, 공장, 성당, 고급 주택가, 호텔.
- **VLS**(3일차~, 금지 구역 아닌 지역의 하이퍼루프가 전환): 최대 3명 함께 발사, 7초 활강, 호스트가 방향 결정. 착지 시 자신·아군 1초, 주변 적 0.5초 기절(팬덤: 적 0.75초 ⚠). 비행 중 금지 구역 통과 시 타이머 소모, 0이면 폭사. 팬덤: 초기 하강 25m/s, 최대 이동 약 130m.

### 5.5 보안 콘솔 / CCTV
- 각 지역에 보안 콘솔이 있고, 작동하면 그 지역 CCTV 카메라들이 작동한 팀에게 시야 제공(팬덤). 작동 시 5크레딧, 지역 야생동물 위치 5초 공개, 지역 상자에 남은 아이템 수량 표시(팬덤).
- 작동 후 10초 쿨다운 뒤 다른 팀이 탈환 가능. 아군 점령 = 초록불, 적 점령 = 빨간불, 비활성 = 꺼짐. **Alt 키**로 CCTV 시야 범위 확인.
- 공식 1.0.0: 보안 콘솔 점령으로 얻는 CCTV 시야는 **90초만 지속**.
- 탐색 숙련도: 보안 콘솔 작동 시 100 숙련도.
- 6일차 밤 이후(임시 안전지대) 보안 콘솔·하이퍼루프·키오스크 등 정지(팬덤).

- **현상금**: 적 처치 시 그가 착용한 전설 장비 가치만큼 현상금 주머니가 시체에 생김. 운석·생명의 나무 장비 10, 미스릴 15, 포스 코어 20, VF 혈액 샘플 30크레딧(나무위키 현재). ⚠ 1.0.0 공지는 25/40/55.

### 5.7 아이템 등급과 제작 / 루트
- 등급: **일반 → 고급 → 희귀 → 영웅 → 전설 → 초월**(색: 영웅 = 보라, 초월 = 빨강으로 커뮤니티에서 통칭 — 나머지 색상은 출처에서 명시적으로 확인 못함 ⚠).
- 장비 부위 5개: 무기, 옷, 머리, 팔/장식, 다리. 무기는 실험체가 쓸 수 있는 무기군만 장착. 그 외 소비(음식·음료), 재료, 특수(카메라·드론·카드키 등) 아이템.
- 제작: 하위 재료 2개를 조합해 상위 아이템을 만드는 방식(블랙서바이벌 계승). 일반 재료는 지역별 배치 + 야생동물 드롭 + 원격 드론. 전설·초월은 특수 재료 필요. 초월 무기는 샤드로 '진홍/새벽' 업그레이드.
- **루트(Route)**: 로비 '전략' 탭에서 미리 작성하는 파밍 계획.
  - 실험체·무기군 선택, 제목 2~16자.
  - 시작 아이템: 각 부위별 **영웅 등급** 아이템 1개씩 지정 → 재료를 모두 얻을 수 있는 장소 2~3곳을 순서대로 지정(부족하면 장소 추가 또는 최대 2종 원격 드론 재료 지정).
  - 전술 스킬 선택, 후반 아이템 리스트(영웅/전설/초월, 전술 강화 모듈 주문 시점), 추가 리스트 최대 5개(리스트당 5종).
  - 인게임에서 화면 우측에 현재 지역에서 주워야 할 재료 표시. 기준: '3루트'(3지역)면 1일차 낮 1분 20초까지 영웅(보라) 장비 완성 권장.
- 대부분의 실험체는 초반에 무기·다리(이동속도) 우선 제작 권장.

## 6. 시야 시스템

### 6.1 기본 시야와 낮/밤
- 낮 8.5m, 밤에는 급감 후 점진 회복(팬덤 3.4m → 6.4m, 8.6에서 밤 감소 효과 5% 완화). 휴식 중 감소. 탐색 숙련도 레벨당 +0.01m(나무위키).
- 시야 밖은 전장의 안개(FOW). 1.0.0에서 FOW가 낮/밤 모두 더 어둡게 조정됨.

### 6.2 부쉬(수풀)
- 수풀 안에서는 밖에서 안을 볼 수 없고, 안에 있는 사람끼리는 서로 보임(모래광대버섯의 모래 연막이 "수풀과 완벽히 동일하게 작용"한다는 설명에서 확인).
- 부쉬 진입으로 발동하는 패시브 존재(테오도르, 프리야 Q 등). 코발트의 '스텔스 필드' = 부쉬.
- 날씨: 쾌청 시 수풀 감소, 비 시 수풀 증가.
- 부쉬 안 카메라 설치가 기본 전술(망원 카메라로 부쉬를 밝힘). 절대 시야(트루 사이트)가 있으면 은신/위장 감지.

- 특정 행동 시 소음 발생 → 일정 거리 내 실험체의 미니맵에 **소음 핑** 표시. 팬덤: 제작 시 **30m** 범위, 야생동물·실험체 처치 시에도 발생(거리 미기재 ⚠).

### 6.5 날씨(기상 변화, 시즌 4 / 패치 1.22 도입)
캐릭터 선택 전에 메인 1 + 서브 1이 정해져 한 판 동안 고정.
