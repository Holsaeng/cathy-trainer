## 현행 정책 핵심 (2025-08-07)
- **창작성 필수**: 단순 편집·복제 불가. 팬키트를 그대로 또는 색 변경·필터·재배치 정도로만 쓰는 것은 창작으로 인정 안 됨.
- **금지**: 게임·회사 이미지 훼손 / 타인 권리 침해 / 차별·혐오 / 선정적 / 폭력·불쾌 / **공식으로 오인될 수 있는 제작·게시** / **공식 로고·이름·UI의 무단 사용·모방** / 공식 굿즈 모조품 / **파생 저작물 기반 2D·3D 모델의 판매 또는 배포**.
- **비상업 수익(별도 승인 불필요)**: 무료 플랫폼 영상 광고 수익, 방송 기본 수익, 블로그 광고, 자발적 후원.
- **플랫폼별**: 방송·영상·블로그 허용 범위 명시. VRChat은 아바타·월드 제작·공유는 허용하되 **제3자 채널로 판매·배포는 무상이어도 금지**. **그 밖의 플랫폼은 사전에 회사와 상의**.
- **제3자 플랫폼 판매**: 사업자 등록 불필요한 플랫폼 + 간편결제 + 연 2천만 원 이하일 때만. 피규어 등 3D 조형물은 판매량과 무관하게 사전 서면 승인.
- **ICP(Independent Creation Program)**: 소설·웹툰·게임 등 상업 프로젝트는 사전 승인 신청. 승인 시에도 공식 리소스·로고·이름은 별도 승인 없이 사용 불가, 「ICP로 제작된 2차 창작물이며 님블뉴런과 무관」 고지 의무.

## 이 프로젝트(캐시 수련장)에 대입
| 항목 | 상태 | 판단 |
|---|---|---|
| 비상업·무료 연습 도구 | 수익 없음 | 비상업 범위 |
| 공식 오인 방지 | 메뉴·README에 비공식 표기 | 충족 |
| 공식 리소스(로고·일러스트·게임 모델·UI) | 사용 안 함 | 충족 |
| 실험체 이름(캐시·다니엘)·게임명 표기 | 사용 중 | 「공식 이름 무단 사용」 조항과 겹칠 수 있음 → 회사 확인 권장 |
| **3D 모델 데이터 온라인 배포**(`models/*.glb`, 직접 만든 모델) | GitHub Pages로 배포 중 | 금지 대상은 「파생 저작물 기반」 모델. CC0 범용 모델·일반 요소 모델은 파생물이 아니라는 입장이지만, 개정 공지가 이 항목을 「제한 유지」로 콕 집은 만큼 **가장 위험한 지점**. 원작풍 설계는 `local/`에만 둠 |
| 팬 게임·도구 형태 | 브라우저 시뮬레이터 | 정책의 「기타 플랫폼」 → **사전 상의 대상** |

## 권장 조치
1. 고객센터(1:1 문의) 또는 eternalreturn@nimbleneuron.com 으로 비상업 팬 연습 도구 운영·3D 표현 범위를 문의하고 답변을 보관.
2. 답변 전까지 공개판은 일반 요소 기준(README 「IP 기준선」) 유지, 원작풍은 로컬 전용.
