# CATHY 수련장 — 이터널 리턴 캐시 수련 시뮬레이터

이터널 리턴의 실험체 **캐시(Cathy)** 숙련도를 올리기 위한 브라우저 미니게임입니다.
HTML 파일 하나로 동작하며, 설치 없이 `cathy_trainer.html`을 브라우저로 열면 바로 플레이할 수 있습니다.

> 팬이 만든 비공식 연습 도구입니다. 이터널 리턴과 등장 캐릭터의 권리는 님블뉴런(Nimble Neuron)에 있습니다.

## 실행 방법
- **웹에서 바로 플레이: https://holsaeng.github.io/cathy-trainer/**
- 또는 `cathy_trainer.html`을 내려받아 브라우저(크롬·엣지 권장)로 엽니다.
- 1920×1080, 1280×720 화면 모두 지원합니다.

## 모드
| 모드 | 내용 |
|---|---|
| 허수아비 | DPS·스킬별 피해 비율 측정, 체력·방어력·무한 체력 설정 |
| 콤보 트레이너 | 정해진 콤보 순서·입력 간격(ms) 판정, 입문/숙련/마스터. 기본 콤보 + 유튜브 가이드 콤보, JSON으로 직접 추가 |
| 회피 수련 | 직선·장판·지연 폭발 패턴, 생존 시간 & 피격 히트맵 |
| 실험체 선택 | 캐시 / **다니엘**(플레이어블: Q 그림자 가위·W 영감·E 그림자 이동·R 걸작·단검, 랭크 영상 HUD 능력치) — 다니엘은 결투·허수아비·회피 모드 |
| 1:1 결투 | 원딜 AI(아야·리오·나딘·카티야) + 근접 암살자 다니엘(은신 진입·걸작) 상대 3판 2선승, 실제 스킬. 상대 레벨(Lv6/12/18), 맵(기본·숲길), 야생동물 선택, 시야 시스템(낮 8.5m·밤 3.4→6.4m, 높은 벽 암시야·낮은 턱/창문 벽 투과, 소음 핑·발소리·부쉬 흔들림, 망원 카메라·정찰 드론), 크로노 스피어(시즌 12 임시 안전지대) 옵션 |

## 조작
- **우클릭** 이동 / 적 위에서 우클릭 = 평타 · **A + 좌클릭** 공격 이동 · **S** 정지
- **Q W E R** 스킬 · **D** 무기 스킬(단검·쌍검) · **F** 전술 스킬(메뉴에서 선택: 블링크·리펄서 미사일·붉은 폭풍·라이트 윙·진실의 칼날·플라즈마 대시·퀘이크·초월·아티팩트·무효화)
- 시전 방식: 일반 / 스마트(누르면 즉시) / 범위 표시 후 떼면 발동 — 스킬별 지정 가능
- **C** 망원 카메라 · **V** 정찰 드론 (결투) · **X** 휴식
- **ESC** 일시정지·설정·결과 · **Tab** 통계 패널
- 메뉴: 모드 카드의 「▶ 바로 시작」(마지막 옵션), **1~4** 모드 옵션, **Enter** 최근 플레이 다시 · 결과 화면 **R** 다시 하기 · **M** 메뉴

## 구현된 캐시 메커니즘
- 외과 전문의: 스킬별 외상 1회(12.0b), 3중첩 치명적 외상(고정 피해·치유 감소·보호막·Q 쿨감)
- 강화 평타(무기 스킬 포함, 시즌 12), 쌍검 일반 평타 80% × 2회
- 수쳐: 관통 후 유도·판정 보정, 2인 수쳐·벽꿍 기절(야생동물 포함), 발사형이라 선딜 중 이동해도 끊기지 않음
- 동맥절제술 벽 통과, 이머전시 OP 정신집중 후 저지 불가 돌진

## 수치 출처
- 스킬·무기·피해 공식: 나무위키 「캐시(이터널 리턴)」, 실험체·무기·무기 스킬·가이드 문서
- 능력치(레벨별 공격력·스킬 증폭·공속·치명·방어력·체력·이속): 유튜브 랭크 플레이 영상 HUD 실측
- 스킬 타이밍·연출·콤보: 캐시 스킬 영상, 유튜브 콤보·입문·원딜 강의 영상, 다니엘 랭킹 1위 강의(네브짱 장인초대석)
- 추정치는 코드의 `CONFIG`에 `TODO`로 표시되어 있습니다.

## 개발
소스는 `src/`의 조각 파일이며, 빌드하면 `cathy_trainer.html` 하나로 합쳐집니다.

```bash
node build.js
```

| 파일 | 내용 |
|---|---|
| `src/1_head_config.html` | HTML/CSS + `CONFIG`(모든 수치) |
| `src/2_core.js` | 유틸·충돌·시야·사운드·이펙트·전투 공식·패시브 |
| `src/3_entities_skills.js` | 유닛·캐시·스킬 구현·투사체 |
| `src/4_ai_stats.js` | 표적/결투 AI 공통 움직임·통계 |
| `src/4_b_kits.js` | 원딜 4명 실제 스킬 키트 |
| `src/3_z_wards.js` | 시야 아이템(망원 카메라·정찰 드론) |
| `src/3_z_daniel_player.js` | 플레이어블 다니엘 |
| `src/3_z_rest.js` | X 휴식 |
| `src/4_c_daniel.js` | 다니엘(근접 암살자) AI 키트·판단 |
| `src/5_modes.js` | 게임 모드 |
| `src/6_game_render.js` | 게임 루프·입력·렌더·HUD |
| `src/7_ui_boot.js` | 메뉴·설정·결과 화면·차트 |
