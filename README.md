# CATHY 수련장 — 이터널 리턴 캐시 수련 시뮬레이터

이터널 리턴의 실험체 **캐시(Cathy)** 숙련도를 올리기 위한 브라우저 미니게임입니다.
HTML 파일 하나로 동작하며, 설치 없이 `cathy_trainer.html`을 브라우저로 열면 바로 플레이할 수 있습니다.

> 팬이 만든 **비공식** 연습 도구이며, 님블뉴런(Nimble Neuron)과 관련이 없고 공식 지원을 받지 않습니다. 이터널 리턴이라는 게임명과 실험체 이름·설정 등 모든 권리는 님블뉴런에 있으며, 연습 목적으로만 이름을 표기합니다.
> **님블뉴런 IP 이용 정책(2025-08-07)에 맞는지 회사에 확인 문의 중**이며, 권리자의 요청이 있으면 즉시 수정하거나 삭제합니다(`docs/ip_policy_notes.md`).
> [님블뉴런 IP 이용 정책](https://support.playeternalreturn.com/hc/en-us/articles/49503976113177-Nimble-Neuron-IP-Usage-Policy-August-7th-2025)에 따라 공식 로고·일러스트·게임 모델·UI는 사용하지 않습니다. 3D 캐릭터는 직접 만든 로우폴리 모델 또는 CC0(자유 이용) 범용 모델을 색·소품으로 꾸민 것입니다. 비상업 목적이며 수익을 얻지 않습니다.

## IP 기준선 (3D 캐릭터 외형)
님블뉴런 IP 정책은 **파생 저작물 기반 2D/3D 모델의 배포**를 금지합니다. 그래서 공개판 3D 캐릭터는 「모델만 보고 이터널 리턴의 그 캐릭터라고 알아볼 수 없는」 선을 지킵니다.

| 쓰는 것 — 일반 요소 | 넣지 않는 것 — 원본 고유 요소 |
|---|---|
| 캐시: 흰 롱코트(무채색 파이핑), 빨간 상의 + 차콜 스카프, 검은 미니스커트 + 발끝까지 이어지는 타이츠, 하이힐, 검은 장갑, 허리 벨트 하나, 갈색 긴 포니테일 + 빨간 리본, 청진기·메스 파우치 | 캐시: 완장(문양), 허벅지 붕대 + 허벅지 스타킹 조합, 가운 밑단 회청 띠·가위 장식, 사선 스트랩 배치, 스커트 트임, 파란 상의·스카프·리본 배색, 톱날 무기 |
| 다니엘: 설정상 직업(미용사)의 일반 요소 — 검은 장발, 짙은 재킷, 미용사 앞치마·가위·빗, 단검 | 다니엘: 보라 장발, 버클 스트랩 롱코트, 보라 장식·띠 |
| 무기 종류(단검·쌍검)와 일반적인 칼 모양, 역할 소품 | 원본 일러스트·게임 모델·얼굴 재현, 공식 로고·UI·스킨 디자인 |

직접 만든 모델(`src/6_y_designs.js` → 게임 `src/6_y_procgen.js` · Blender `tools/blender/make_model.py`)과 CC0 모델 꾸미기 모두 이 기준을 따릅니다.

> **2026-10-07부터 (저장소 관리자 결정)**: 공개판에도 직접 만든 Blender 모델(`models/cathy_custom.glb`·`models/daniel_custom.glb`, 기본 3D 모델)과 원작풍 설계(`models/cathy_ref.json`, 설정 → 그래픽 → 「원작풍」 선택 시, 위 표의 원본 고유 요소 일부 포함)를 올립니다. 권리자의 요청이 있으면 즉시 내립니다.

## 조작
- **우클릭** 이동 / 적 위에서 우클릭 = 평타 · **A + 좌클릭** 공격 이동 · **S** 정지
- **Q W E R** 스킬 · **D** 무기 스킬(단검·쌍검) · **F** 전술 스킬(메뉴에서 선택: 블링크·리펄서 미사일·붉은 폭풍·라이트 윙·진실의 칼날·플라즈마 대시·퀘이크·초월·아티팩트·무효화)
- 시전 방식: 일반 / 스마트(누르면 즉시) / 범위 표시 후 떼면 발동 — 스킬별 지정 가능
- **C** 망원 카메라 · **V** 정찰 드론 (결투) · **X** 휴식
- 3D 그래픽: **카툰 렌더링**(셀 셰이딩 3단 + 검은 외곽선, 캐릭터·벽) · **3D 스킬 이펙트**(베기·돌진 궤적·불꽃·칼 궤적) — 설정 → 그래픽에서 각각 켜고 끄기
- 3D 시점: 이터널 리턴처럼 높이 내려다보는 시점(탑뷰와 쿼터뷰 사이) · 마우스 휠 줌(가까이 당기면 카메라가 눕어 모델을 자세히 볼 수 있음) · **Y** 카메라 잠금 전환(풀면 화면 가장자리로 이동) · **스페이스**(누르고 있기) 내 캐릭터로
- 3D 환경: 낮↔밤이 3초에 걸쳐 노을을 지나며 바뀜 · 크로노 스피어 차단벽이 붉게 일렁이는 빛의 벽으로 · **날씨**(설정 → 그래픽: 맑음·비·안개, 보기만 바뀌고 판정은 그대로 · 비 오면 빗소리·천둥)
- **🛠 상대 장비**: 결투 옵션 「상대 장비」 → 실측(기본) / 인기 1 / 인기 2 / 시작(영웅). AI 상대가 시즌 12 인기 빌드로 계산한 능력치(쿨감·관통·흡혈 포함)로 싸움, 기록은 상대 장비별

## 개발
소스는 `src/`의 조각 파일이며, 빌드하면 `cathy_trainer.html` 하나로 합쳐집니다.

```bash
node build.js          # cathy_trainer.html
node build.js --test   # + cathy_trainer.test.html — 열면 회귀 테스트(tests/regression.js)가 자동 실행, 결과가 화면 상단과 탭 제목에 표시
```

변경할 때마다 테스트 빌드를 열어 `TEST PASS`인지 확인합니다.

**구조**: 게임 로직(이동·스킬·충돌·시야·AI)은 미터 단위 평면 좌표만 다루고, 화면 표시는 `Renderer`가 담당합니다. 현재 구현은 2D 캔버스(`Render`)이며, 체력바·글자·HUD는 렌더러와 무관한 `ScreenLayer`가 그립니다. 3D 렌더러(`Render3D`, Three.js r128 CDN)도 같은 인터페이스(`init / frame / toWorld / toScreen / pxPerMeter / overhead / inputCanvas`)로 붙어 있고, 메인 메뉴·설정에서 2D/3D를 고릅니다. 3D는 벽·부쉬·유닛·투사체를 3D 메시로, 예고 범위·이펙트·시야 안개는 2D 그리기 코드를 바닥 텍스처(데칼)에 그려 재사용합니다. 라이브러리를 불러오지 못하면 2D로 자동 전환됩니다.

**3D 인물 모델**: [Quaternius](https://quaternius.com)의 CC0 모델(Ultimate Modular Women/Men Pack, [Poly Pizza](https://poly.pizza) 배포본)을 수정 없이 `models/`에 두고, 게임 안에서 색·무기와 역할을 나타내는 일반 소품(외과의 가운·청진기, 암살자 후드·마스크, 모자·화살통 등 — 특정 캐릭터 디자인을 재현하지 않음)을 뼈대에 붙여 캐시·다니엘·원딜 AI 느낌을 냅니다. 달리기·칼 휘두르기·사격·피격 애니메이션이 상태에 맞춰 재생됩니다. 캐시는 평타(단검 베기↔찌르기, 쌍검 오른손·왼손 대각 2연타, 강화 평타 크게 베기·쌍검 X자 교차 베기)와 스킬(Q 찌르며 돌진, W 휘두르기, E 던지기, R 정신집중→숙여 돌진 베기, D 뒤로 이동 찌르기·쌍검 연속 찌르기)이 판정 시간에 맞춰 재생되어, 피해가 들어가는 순간 칼끝이 닿습니다. 웹(GitHub Pages)에서만 불러오며, HTML만 내려받아 열거나 불러오지 못하면 기존 로우폴리 인형으로 표시됩니다(설정 → 그래픽에서 끌 수 있음). 테스트를 웹 서버로 열면 모델 경로까지 검사합니다.
