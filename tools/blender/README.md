# 방법 2 — Blender로 캐릭터 모델 만들기

게임 안에서 코드로 만드는 모델(`src/6_y_procgen.js`, 방법 1)과 **같은 설계 파일(`src/6_y_designs.js`)** 을 Blender에서 읽어 매끄럽게 만드는 경로입니다. 설계를 한 번 고치면 두 모델이 같이 바뀝니다.

| | 방법 1 (게임 코드) | 방법 2 (Blender) |
|---|---|---|
| 필요한 것 | 없음 | Blender 4.x ~ 5.x (5.2에서 확인) |
| 표면 | 각진 로우폴리 | 부드러운 음영 · 옷 두께 |
| 뼈대 가중치 | 가까운 뼈 2개 거리 비율 | 같은 규칙 (자동 가중치는 겹친 부품에서 실패해 쓰지 않음) |
| 결과 | 실행할 때마다 생성 | `models/<키>_custom.glb` |

## 실행
```bash
bash tools/blender/run.sh
```
하나만:
```bash
bash tools/blender/run.sh daniel
```

- 결과 `models/<키>_custom.glb`가 있으면 게임이 자동으로 읽고, 설정 → 그래픽 → <실험체> 3D 모델에 **Blender 모델** 버튼이 생깁니다.
- `tools/blender/preview_<키>.png`에 정면·측면·뒷면 미리보기가 렌더됩니다.
- 게임은 이 파일에서 **모양(메시·음영·가중치)만** 가져와 원본 CC0 뼈대(`models/*_base.glb`)에 다시 붙입니다(`Procgen.rebind`). Blender로 내보내면 뼈의 기본 방향·끝점이 다시 계산돼 다리 동작이 어긋나기 때문이에요. 그래서 평타 동기화·쌍검 동작·스킬 동작·다리 보정이 원본과 똑같이 동작합니다.
- 모양을 바꿀 땐 `src/6_y_designs.js`의 수치를 고칩니다(형식은 파일 안 `_doc`). 새 실험체는 설계를 추가하고 `Models.CUSTOM`에 키를 넣으면 됩니다.

## 저작권
CC0 모델의 뼈대·애니메이션만 쓰고 모양은 직접 만든 것입니다. 님블뉴런 IP 정책상 이터널 리턴 캐릭터 디자인을 재현하지 않고 일반 요소로만 만듭니다 — 캐시: 실전파 외과의(청록 수술복 + 소매 걷은 흰 가운 + 연파랑 장갑·수술 마스크 + 휘어지는 긴 포니테일), 다니엘: 미용사 겸 암살자(검은 장발 + 짙은 재킷 + 미용사 앞치마·가위). 기준표는 루트 README 「IP 기준선」.
